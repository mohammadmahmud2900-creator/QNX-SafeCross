🚗 QNX SafeCross - Save Lives in 8ms

The Problem
Every year, thousands of pedestrians die because cars react too late.
A human driver needs *1.5 seconds* to brake. That's too late.

Our Solution
*SafeCross* is a real-time pedestrian safety system built on *QNX*.
It detects a pedestrian and stops the car in just *8 milliseconds*.

> Human: 1500ms ❌
> SafeCross: 8ms ✅ - *187x Faster*

How It Works
1.  *Detect:* Sensor detects pedestrian on road
2.  *Decide:* QNX Real-Time OS processes in microseconds
3.  *Stop:* Emergency Brake activates instantly
